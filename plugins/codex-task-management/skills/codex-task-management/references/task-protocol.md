# 任务书与回执

派工、创建或更新模块卡、回传结果时读取本页。字段保留在原任务卡或原生消息，不另建报告副本；执行规则见 [SKILL.md](../SKILL.md)。

## 任务书与单任务卡

首次派工后才创建任务卡，不预建空模块目录。确实不适用时写原因，依赖或授权未满足时明确说明；创建产生的身份和位置由主控核验补齐后再接单。

```markdown
# <任务标识>：<目标>
- 任务身份：稳定任务标识 / 模块名称 / 模块 Codex 任务 ID / 主控 Codex 任务 ID
- 工作位置：主机 / 绝对工作树路径 / 分支 / 唯一 writer / 任务卡与权威索引绝对路径
- 目标与范围：真实场景 / 预期行为 / 做什么 / 不做什么
- 文件归属：允许修改的文件或目录 / 公共文件负责人
- 交付形态：skill / 代码 / 文档（流程节点默认 skill 形态；skill 交付的验收含安装态 agent 发现+加载+按批准样本调用）
- 执行基线：已核验的 main SHA / 实际 Skill 路径与内容指纹 / 适用规则与字段、接口合同路径及版本
- 输入与依赖：上游任务 / 输入合同 / 真实证据入口 / 依赖满足条件
- 交付要求：功能、文件、接口或数据 / 下游使用方式
- 验收条目：稳定编号 / 预期结果 / 样本 / 验证方法或命令 / 所需验证等级与证据
- 验收位置：按编号填写合并前/后或不涉及合并、主机、绝对执行目录、目标类型及位置、执行人和判定人；目标可为服务、CLI、Skill目录及使用它的任务上下文，外部系统另列实际目标
- 当前阶段与授权范围：当前工作及已有实施授权 / 目标、边界与可定位的授权依据；不逐阶段请求批准
- 操作边界：外部读写目标与范围、读回方法 / 提交、合并、推送分别授权 / 设备或会话约束
- 当前检查点：带时区的更新时间 / 实际环境及基线核对 / 已完成 / 未完成 / 阻塞及原因
- 关键决定与理由：仅接班必需结论
- 交付检查点：下方最终回执字段及证据入口；未到交付阶段写明
- 下一步：动作 / 负责人 / 是否需要人工决策及具体问题
```

未提交规则、合同或候选附可读原件、完整差异及内容指纹，不能仅凭 HEAD 判断一致。验收编号保持稳定，范围变化须记录获批的新旧条目对应关系。

验收位置不能用开发工作树代替，不能只填“本地”或“同上”；共用位置可合并列出验收编号。环境未知写待核验及负责人，不因填写部署条目自动创建环境或获得权限。回执记录最终实际位置和所验版本。

修正次数只由主控写权威索引，卡内不另计；仅作诊断与历史记录，不作为自动推进配额或人工审批门槛。获批外部动作执行前记录目标和意图，执行后补精确读回；结果不明不重放。必要原始证据脱敏，记录来源系统、采集时间、方法和内容哈希。

## 五类回执

所有回执都包含以下公共字段，再按类型补充相关内容：

```markdown
- 任务标识：
- 回执类型：接单 / 方案送审 / 阶段进展 / 阻塞 / 交付待验收（选一）
- 当前阶段：
- 更新时间：带时区
- 结果摘要：已完成什么、还缺什么
- 任务卡入口：主机与绝对路径
- 下一步及负责人：
```

回执可能因流层故障未送达：模块发现自身终结消息疑似丢失时，应在下一轮主动重发同一回执，不计为重复通知。

| 类型 | 补充字段 |
| --- | --- |
| 接单 | 实际主机、工作树、分支、HEAD、Git 状态、writer、Skill/规则/合同指纹；依赖核对与可执行范围 |
| 方案送审 | 方案入口及版本、关键决定、适用合同、独立评审结果与现有授权依据；仅确需用户决策或缺少授权时列明缺项，同范围技术方案不逐次请批 |
| 阶段进展 | 阶段产物、相关验收编号及证据、未完成项 |
| 阻塞 | 失败步骤、脱敏错误、最后已验证检查点、受影响验收条目、所需动作或决策及负责人 |
| 交付待验收 | 下表全部字段；无操作、未验证或不适用明确标注并说明 |

| 最终回执字段 | 内容 |
| --- | --- |
| 实际交付 | 完成与未完成项、实际修改文件、相对批准范围的偏离 |
| 候选版本 | 比较基线、提交 SHA 或完整未提交差异；新增文件与内容指纹；是否冻结 |
| 逐项验收结果 | 原验收编号及通过/失败/未验证/不适用，附原因和证据；仅约定需人工验收时附原模块确认位置、原文、时间、候选及条目 |
| 验证记录 | 验收编号、合并阶段、实际命令、主机、绝对目录、目标类型/位置、候选版本、执行人/判定人、结果及证据；Skill另含实际加载路径、内容指纹与调用结果；区分 unit verified、snapshot verified、sandbox verified、live verified |
| 独立评审 | 评审者、结论、覆盖候选和阻断问题；未评审明确标注 |
| 外部操作 | 未发生；或授权、实际目标、动作、时间、脱敏请求/响应摘要、精确读回证据 |
| 阻塞与遗留 | 影响的验收条目及负责人；区分阻断与非阻断后续事项 |
| 交接状态 | writer是否停止、运行任务与资源占用、成果与恢复资料位置 |

只引用对应本次候选与真实目标的原始证据，不以旧版本结论代替，不复制原始日志。回传“交付待验收”不代表主控已通过或可自行清理。
