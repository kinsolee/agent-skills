# 任务书与关键事件

任务书写 issue description；最终决定、实际阻断和交付写 issue comment。普通进展留在任务对话，不复制父任务。执行规则见 [SKILL.md](../SKILL.md)。

## 任务书

```markdown
## 目标与交付
<真实场景、完成点、范围、已有授权；调查或实施；交付物、验收等级 unit|snapshot|sandbox|live 与证据入口>

## 归属
- 责任人：<正式 thread ID；创建中的临时 ID 仅标记创建中>
- 允许修改：<文件/目录，含需要写入的辅助仓库>
- 共享文件/资源：<有实际争用时写唯一负责人或串行安排>

## 基线与依赖
- 基线：<已提交 SHA>
- blocked_by：<真实依赖 issue 与原因 functional|serialization；无则无>
- 输入合同：<真实证据入口>

## required_checks
- <本地验证命令>
```

需要协调者时仅在相关 parent 记录身份与跨任务职责。land.sh 会在交付 worktree 逐条执行 `## required_checks` 下 `- ` 开头的内容；只放本地验证命令，不放解释或外部写入操作，任一失败中止合并。人工检查写在交付要求。

## 关键事件

| 事件 | 必要记录 |
| --- | --- |
| 接单/启动 | claim 自动记绑定与 worktree；启动时补实际分支/HEAD 与登记一致、已开始或实际缺口，只核对一次 |
| 最终决定 | 负责人确认的结论、授权范围、权威入口；共享定义变化列受影响任务，各任务记录同步后的已提交 SHA |
| 实际阻断 | 失败证据、影响范围、已尝试动作、候选检查点、恢复条件及谁提供缺失项 |
| 交付 | 冻结 SHA、检查结果与验证等级、最终版本独立评审结论、遗留项，直接交负责人验收 |
| 替换归档 | 新旧正式 thread ID/host、交接入口和阶段、旧 writer 停止依据、宿主归档读回；失败则记待归档对象 |
| landed | land 自动记 landed_sha、冻结 SHA、合并方向、检查结果、用户批准与时间，随后转 done |

复用已有证据入口和有效检查结果，不重复抄录；缺失资料可在授权内查证时自行补齐。只读交接注明候选位置和写入权未转移；待审候选保持冻结。
